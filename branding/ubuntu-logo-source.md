The kernel Ubuntu wordmark is derived from `/usr/share/plymouth/themes/spinner/watermark.png`
in Ubuntu's `plymouth-theme-spinner` version
`24.004.60+git20250831.4a3c171d-0ubuntu10` (Ubuntu archive, arm64).
It is scaled 2x onto an 800x200 black canvas and quantized to 220 colours for
the kernel's CLUT224 logo converter. Ubuntu branding belongs to Canonical.
This is an unofficial device port, not an official Ubuntu product.

The existing Shero logo remains available for the historical build scripts.
